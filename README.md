# 🌸 HAPPY RAKSHA BANDHAN 🌸

A festive website celebrating the beautiful bond between siblings on Raksha Bandhan!

## 📋 About
This is a heartfelt greeting website dedicated to wishing joy, love, and the special bond of siblings on Raksha Bandhan - a traditional Indian festival celebrating brother-sister relationships.

## 🎨 Features
- Beautiful gradient background with pink theme
- Animated greeting message
- Interactive surprise button with personalized wishes
- Cartoon illustration of Rakhi ceremony
- Responsive and simple design

## 🚀 How to Use
1. Clone this repository
2. Open `index.html` in your web browser
3. Click the "click for surprise 🎁" button to see the personalized message

## 📁 Files
- **index.html** - Main HTML page with greeting and content
- **style.css** - Styling and design
- **script.js** - Interactive functionality
